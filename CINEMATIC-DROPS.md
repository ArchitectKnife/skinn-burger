# BURGER SKIN — кинодропы (GODLIKE / MYTHIC / DIVINE / KNIFE / GLOVE)

## Установка
1. Остановите сайт и сделайте резервную копию: `npm run backup`.
2. Распакуйте архив в корень проекта с заменой файлов (структура папок сохранена).
3. Запустите сайт: `npm start`. Ставить новые пакеты не нужно, миграций базы нет.
4. Проверка: `npm test` и `node --disable-warning=ExperimentalWarning scripts/cine-test.ts`.

## Настройка
Админ-панель → Система → **Кинодропы** (`/admin/drops`):
- пороги GODLIKE / MYTHIC / DIVINE в рублях (по умолчанию 5 000 / 25 000 / 100 000 ₽);
- условие «не дешевле N × цены кейса» (по умолчанию 1×);
- отдельные сцены для ножей и перчаток, ссылки «Поделиться», режим по умолчанию;
- статистика: сколько цен каталога в каждом уровне и шанс кинодропа по каждому кейсу;
- предпросмотр всех пяти сцен.

Громкость сцен: Админ-панель → Звук → «Кинодропы»; у игрока — в самой сцене и на панели звука.

## Честность
- Предмет выбирается сервером (Provably Fair) и записывается в инвентарь до ответа клиенту.
- Уровень сцены сервер считает по цене уже выданного предмета и сохраняет в ставке.
- Пороги влияют только на выбор сцены; шансы кейсов не меняются (это проверяет `scripts/cine-test.ts`).
- Страница `/drop/<id>-<подпись>` показывает данные из записанной ставки; подпись HMAC не даёт подделать ссылку.

## Новые файлы
- `src/lib/dropfx.ts` — уровни, сцены, подпись ссылок, статистика для админки.
- `public/js/cinematic.js` — движок сцен (WebGL + запасной 2D-режим).
- `public/js/cine-sound.js` — синтезированный звук (WebAudio, без сторонних файлов).
- `public/js/cine-mode.js` — режимы «Полные / Короткие / Выкл», ленивая загрузка.
- `public/cine.css` — стили сцен (грузятся только при кинодропе).
- `public/js/pages/drop.js` — публичная страница дропа.
- `public/js/pages/admin-drops.js` — раздел админки.
- `scripts/cine-test.ts` — автотест.
